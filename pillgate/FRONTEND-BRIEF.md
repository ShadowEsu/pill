## The ten pages (hash routes in one `index.html`, e.g. `#/welcome`; history back/forward must work; deep links must open the page)
1. **Welcome** `#/welcome`: BinaryPill-style hero (ink background, the pill drawn from 0/1 characters, port the idea from `pill/web/src/components/BinaryPill.tsx` to a canvas or pre-rendered text), one serif line, the three modes as cards (Clinic · Personal · Check), device chip (live / REPLAY (not live) / no device, from `/api/live.status.mode`).
2. **Home** `#/` (per mode): Clinic: today's gate (counts from `/api/scans`: passed / needs lab / unable), last 5 scans as capsules, "Start a check"; Personal: "Check my medicine" hero, last scan, how it works strip; Check: straight to the stepper.
3. **Bottle** `#/check/bottle`: Viewfinder-style photo frame (corners, scan line), take/choose, Skip, the privacy line; shows the chosen photo.
4. **Tablet** `#/check/tablet`: same frame, imprint guidance (one tablet, both sides if marked), Skip.
5. **Measure** `#/check/measure`: the guided run as a **phase rail** with real times from `/api/config.timing` and `/api/live.guide`: Prepare (profile pick when needed, Quick 60 s / Full) → Clean water (`guide.phase === "water"`: checks list with ticks, `steady_s / needed` ring) → Add the tablet (beep via Web Audio, 10-s instruction, Continue = `POST /api/run/mark`) → Dissolving (`guide.phase === "dissolving"`: elapsed ring, live Chart.js curve with A_B/A_W/A_R/A_side in the design's line colours, the 12 checkpoints marked in quick mode) → Stop (call `/api/run/stop` the moment `guide.stop` is true, then `POST /api/scans`). Paste-data fallback kept (`/api/run/upload`). The device chip and the live `lines` counter visible.
6. **Result** `#/result/:scanId`: Stamp-style verdict card (ink words; wash green/amber/grey by result), stage list from `scans/{id}.stages` as a live step log while polling, the curve vs reference, label fields, recall status, the report text with numbered sources, Ask and Report-an-issue entry points, "Check another".
7. **Ask** `#/ask/:scanId`: chat grounded in the report (`POST /api/scans/{id}/ask`), voice input where the browser allows (keep the existing SpeechRecognition / speechSynthesis code paths), read-aloud toggle.
8. **Report an issue** `#/issue/:scanId`: draft (`/issue/draft`) shown for editing, Submit (`POST /api/issues`) only on tap, the "no reporter identity is stored" line.
9. **History** `#/history`: runs and scans lists (`/api/runs`, `/api/scans`), each scan a capsule with result + drug + time; opens Result.
10. **Profiles** `#/profiles`: reference / calibration builders exactly as the API expects (`POST /api/profiles/reference` with ticked run ids, `/calibration`), the "what changes when it dissolves" choice, SIMULATED labels as given.
Plus **Atlas** `#/atlas` (the existing 3d-force-graph, created on first open, destroyed on leave) and **Settings** `#/settings` (mode switch, sounds on/off, read-aloud, reset local prefs). These two don't count toward the ten but must keep working.
