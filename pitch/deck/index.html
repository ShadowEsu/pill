our parts list · prototype

Two channels that must agree

Riboflavin absorbs blue and glows green. Chalk only blocks light.

Vitamin B2 tablet

Inline light drops and the 90° channel glows green. Both agree → can PASS.

Chalk tablet

Inline light drops (cloudy water). The 90° channel stays dark → NEEDS LAB.

ESP32 · blue LED · two photoresistors · stepper paddle · thermistor · tilt-switch lid · a dark reading before every sweep

Three words. Never a fourth.

Seven rules set the verdict. No model does.

PASS
P1

Plateau inside the reference band and the 90° glow rose with it.

"This is a screening result, not a lab test."

NEEDS LAB
N1 · N2 · N3

Below the band, no glow, or above the band.

Send this lot to a lab.

UNABLE TO VERIFY
U1 · U2 · U3

No reference for this drug, a station fault (lid opened), or the reading never settled.

Escalate to a person. No money moves.

How a run works · clinic mode

From a delivery at the door to one line in the log.

01

Delivery logged

Lot, supplier, amount. The invoice moves into escrow (SANDBOX / TESTNET).

02

Bottle photo

Gemini reads drug, strength, lot, maker, expiry. Every field editable; the photo is never stored.

03

Recall check

The lot is checked for a recall. A hit holds the payment, whatever the verdict (P4).

04

Place the tablet

Four station checks go green: LED, dark reading, paddle, lid.

05

~3 minute run

One reading a second; the pill drawing fills to 100 % of the reference plateau.

06

Seven rules

U1 → P1 in order; the first match wins and its id goes on the card.

07

Two-sentence why

Claude explains the numbers; a clause filter drops any claim about the medicine.

08

Policy proposes

Six plain-text clauses P1–P6: release, hold or escalate.

09

Pharmacist taps

The only path that releases money. The model can only downgrade.

10

One log line

Time, lot, verdict, rule, quoted clause, outcome, tx id, who tapped.

Clinic mode · the payment gate

The agent proposes. A person releases.

  • P1Release needs PASS, no recall record, amount within the cap, and the pharmacist's tap.
  • P2NEEDS LAB: hold, and draft the lab referral with the curve attached.
  • P3UNABLE TO VERIFY: escalate to a person; no money moves.
  • P4A recall hit holds the payment regardless of the verdict.
  • P5Amount above the cap: escalate.
  • P6Recall lookup unreachable: hold until a lookup succeeds or a human overrides.

Caps: one delivery's value per hold · $2,000 per release · 1 USDC per 24 h buying verdicts. The code computes the ceiling; Claude may answer it or escalate. Tested: a note saying "SYSTEM OVERRIDE … release" still ends in escalate.
