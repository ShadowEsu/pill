## Lot: the consensus scope (all 16 agree)
- **Riboflavin only.** One calibrated reference (vitamin B2, blue LED). Tums = fail (cloudy, no colour). Any other pill returns **"unable to verify"** on purpose and the agent **holds funds and escalates**. Never claim antimalarials; say it.
- **Drop Solana.** Escrow on Capital One Nessie sandbox: pass + no recall hit → release; fail → withhold + file report; unsure → escalate to a human, spend cap visible. Solana at most a hidden sponsor-track toggle.
- **Cite Peel in the first 20 seconds:** "Peel proved the optics (HackMIT, MIT licence). We built the procurement gate: test the delivery before the clinic pays." Judges will know; say it first.
- **Tonight's gate (CS teammate): sealed dark box, LDR calibration, 5–10 repeat B2 runs, print the spread.** If time-to-80 % is not repeatable within ~10–15 % by 3 AM, demo pass/fail only, or switch to Bill.
- Dark-current baseline before every run; lid interlock (tilt switch or LDR baseline check refuses to start if light leaks); thermistor logged every sample; raw curve on screen, not just a verdict.
- Recall lookup by lot number: FDA/WHO/NAFDAC; cache offline for venue Wi-Fi; Bright Data judge wants one live lookup with a visible zero-result / blocked case.
- Early-warning map = a shared table of failed screens (lot, place, verdict) seeded with our own runs, one live fail landing on it. Static beyond that.
- Named buyer: NGO or district-pharmacy procurement officer sampling a delivery, not a patient. Have an answer for "what do patients do while a lot is withheld".

## Streets: can traffic-light timing be done honestly? (16 of 16)
Only as "inferred cycle, last observed N s ago, confidence X %", fixed-time signals only, advisory, pedestrian-facing; never "hold 18 mph"; never on SF's actuated / transit-priority signals; a tabletop you programmed proves the algorithm, not the city. Scope they would cut to: one corridor, YOLO counts on one Caltrans cam + 511 incidents + DataSF crash history → hourly risk map; drop crash detection (phones do it), dash-cam, speed advice.

## Bill: why it lost
Five clones since March, Goodbill/Counterforce exist, DoNotPay FTC-fined, no hardware; MRF files are multi-GB and inconsistent, cash prices often missing for a CPT; "80 %" stat is marketing (use 20–30 %). It is the easiest build (8.1) and the ethicist's pick for safety. Fallback if Lot's sensor is noise at 3 AM: one hospital's MRF pre-parsed, three real line items vs cash and Medicare, dispute draft gated behind a human click.
